# KMC 5년 장기투자 운영계획서

작성일: 2026-06-04  
목적: 우리 부부 및 지인이 매일 들어와도 흔들리지 않도록, KMC를 **장기투자 운영 대시보드**로 재정의한다.

> 주의: 이 문서는 투자 판단 프레임워크다. 특정 종목 매수/매도 지시가 아니라, 5년 장기투자를 위한 섹터 배분, 리밸런싱, 검증, 기록 체계를 정의한다.

## 1. 제품 방향 재정의

KMC는 단기 시세 앱이 아니다. 목표는 5년 동안 구조적으로 성장할 산업을 정하고, 매일 들어와도 감정적으로 흔들리지 않도록 **원칙, 비중, 증빙, 리밸런싱 기준**을 보여주는 장기투자 작업대다.

기존 정의:

```text
밸류체인 캔버스 + 시장 데이터 + 종목 카드 + 개인화 랜딩
```

수정 정의:

```text
5년 장기투자 포트폴리오 운영대장
    = 장기 섹터 배분
    + Musk Stack 검증 레이어
    + 밸류체인별 핵심 종목 후보
    + 과열/저평가 진입 기준
    + 매일 확인할 신호와 금지 행동
```

## 2. 장기투자 기본 원칙

### 2.1 투자 기간

기본 보유 기간은 **5년**으로 둔다.

단, 아래 조건이 발생하면 예외적으로 축소/제외한다.

| 예외 조건 | 조치 |
|---|---|
| 투자 논리 훼손 | 해당 섹터/종목 재검토 |
| 검증등급 하락 | Musk Stack 관계카드 비중 축소 |
| 재무 악화 | 종목 카드 경고 |
| 구조 성장 둔화 | 섹터 등급 Core → Expansion/Watchlist 강등 |
| 과열도 극단 구간 | 신규 매수 중단, 리밸런싱 검토 |

### 2.2 매일 들어와서 봐야 할 것

매일 확인할 것은 가격 자체가 아니라 아래 다섯 가지다.

1. 내 전체 포트폴리오가 원래 정한 섹터 비중에서 벗어났는가
2. Musk Stack 검증등급이 바뀌었는가
3. Core 섹터의 구조적 논리가 훼손됐는가
4. 과열도 때문에 신규 진입을 미뤄야 하는가
5. 공시/수주/정책/실적 중 5년 논리에 영향을 주는 이벤트가 있는가

매일 보면 안 되는 것:

- 당일 등락률만 보고 비중 변경
- 뉴스 제목만 보고 추격 매수
- 검증되지 않은 Musk 관계 루머 반영
- Watchlist 섹터를 Core처럼 매수

## 3. 기준 배분안

사용자 의도에 맞춰 **Musk Stack 20% + 나머지 Core 섹터 분산 80%**를 기본안으로 둔다.

### 3.1 기본 포트폴리오 구조

```text
전체 장기 포트폴리오 100%
├─ Musk Stack 검증 레이어: 20%
└─ Core 섹터 분산: 80%
   ├─ AI 전력 인프라 / Grid Bottleneck
   ├─ AI 반도체 / HBM / Advanced Packaging
   ├─ AI 데이터센터 전력/냉각 인프라
   └─ BESS / 전력 유연성 / ESS
```

### 3.2 권장 기준 비중

| 구분 | 비중 | 역할 |
|---|---:|---|
| Musk Stack 검증 레이어 | 20% | 차별화 알파. 직접/간접 관계가 검증된 종목만 편입 |
| AI 전력 인프라 / Grid Bottleneck | 25% | 5년 장기 핵심. 변압기, 배전, 케이블, 전력관리 |
| AI 반도체 / HBM / Advanced Packaging | 25% | AI CAPEX 핵심. HBM, 패키징, 기판, 후공정 |
| AI 데이터센터 전력/냉각 인프라 | 15% | 전력/냉각/랙 통합 수혜. 고밀도 AI 인프라 |
| BESS / 전력 유연성 / ESS | 15% | 전력망 병목 완화. 저장장치, PCS, 운영 |

합계: 100%

### 3.3 대안 배분

| 성향 | Musk Stack | 전력 인프라 | 반도체/HBM | 데이터센터 인프라 | BESS/ESS |
|---|---:|---:|---:|---:|---:|
| 안정형 | 10% | 30% | 25% | 15% | 20% |
| 기본형 | 20% | 25% | 25% | 15% | 15% |
| 공격형 | 25% | 20% | 30% | 15% | 10% |

KMC 기본 화면은 `기본형`을 기준으로 설계한다. 단, 가족/지인마다 투자 성향이 다르면 성향 프리셋을 선택할 수 있게 한다.

## 4. Musk Stack 20% 운영 원칙

Musk Stack은 매력적인 알파 레이어지만, 가장 흔들리기 쉬운 영역이기도 하다. 그래서 독립 섹터가 아니라 **검증등급이 붙은 관계 레이어**로 운영한다.

### 4.1 편입 기준

Musk Stack 20%에는 아래 중 하나를 만족하는 항목만 들어간다.

| 등급 | 편입 가능 여부 | 기준 |
|---|---|---|
| A | 가능 | 직접 계약/납품/공식 문서 확인 |
| B | 가능 | 공식 언급 + 신뢰 가능한 2차 자료 |
| C | 제한 가능 | 간접 공급망. 비중 상한 필요 |
| D | 불가 | 연관성만 있음 |
| X | 불가 | 루머/커뮤니티 주장 |

### 4.2 비중 제한

```text
Musk Stack 20%
├─ A등급 관계: 최대 60%
├─ B등급 관계: 최대 30%
├─ C등급 관계: 최대 10%
└─ D/X 등급: 0%
```

즉 전체 포트폴리오 기준으로 보면:

| 관계등급 | 전체 포트폴리오 내 최대 비중 |
|---|---:|
| A | 12% |
| B | 6% |
| C | 2% |
| D/X | 0% |

### 4.3 Musk Stack에서 금지할 것

- `테슬라 수혜주`라는 말만으로 편입
- xAI, SpaceX, Tesla와 공식 관계가 없는 종목을 직접 수혜처럼 표시
- 비상장사 가치 상승을 상장 종목 수혜로 자동 연결
- 루머를 C등급 이상으로 표시

## 8. 리밸런싱 원칙

### 8.1 주기

| 주기 | 작업 |
|---|---|
| 매일 | 이상 신호 확인만 |
| 매주 | 섹터별 과열도/뉴스/공시 검토 |

### 8.2 리밸런싱 조건

아래 중 2개 이상 충족할 때만 리밸런싱한다.

1. 기준 비중 대비 ±5% 이상 이탈
2. 섹터 투자 논리 훼손
3. Musk Stack 검증등급 변경
4. 과열도 85 이상이 장기간 유지
5. 실적/수주/정책이 장기 방향과 반대로 이동

## 13. 최종 운영 방향

KMC는 앞으로 아래 순서로 잡는 것이 맞다.

1. `5년 투자 원칙` 페이지를 첫 탭으로 둔다.
2. 전체 기준 배분은 `Musk Stack 20% + Core 섹터 80%`로 둔다.
3. Core 섹터는 4개만 깊게 운영한다.
4. Musk Stack은 관계 검증등급 없이는 편입하지 않는다.
5. 매일 들어오면 “오늘 할 일”보다 “오늘 하지 말아야 할 일”을 먼저 보여준다.
6. 리밸런싱은 매일이 아니라 월간/분기 기준으로 한다.
7. 단기 등락보다 5년 논리 훼손 여부를 최상단에 둔다.

## 14. 한 줄 결론

KMC의 첫 화면은 뉴스나 히트맵이 아니라 **우리의 5년 투자 원칙을 지키는 계기판**이어야 한다.

```text
Musk Stack은 20%만.
나머지는 AI 전력, HBM, 데이터센터 인프라, BESS에 분산.
증빙 없는 관계는 사지 않고, 과열 구간은 기다린다.
```
